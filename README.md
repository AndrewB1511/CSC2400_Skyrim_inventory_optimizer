# CSC2400_Skyrim_inventory_optimizer
3 different algorithmic approaches to solving inventory optimization on a data set from Skyrims wiki.
To compile this code run this command g++ -std=c++17 -O2 -Wall -Wextra main.cpp item.cpp dynamic.cpp -o skyrim_dp.exe then to execute the compiled program run this skyrim_dp.exe "your data file here".txt 150 100
